# Índice de funcionalidades

Documentação detalhada por funcionalidade (fluxos de negócio, telas, integrações) deve ser adicionada nesta pasta, seguindo o padrão `NN-NomeTema.md` (ex.: `02-OrcamentoMensal.md`).

Módulos principais do sistema:

- **financial**: categorias, despesas fixas, lançamentos mensais.
- **credit-cards**: cartões, faturas, compras e parcelas.
- **dashboard**: resumos e séries agregadas.
- **budget**: orçamento e metas no escopo do módulo correspondente.
